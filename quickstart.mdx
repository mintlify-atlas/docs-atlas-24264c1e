title: "Quickstart: run Taller de Inglés locally in minutes"
sidebarTitle: "Quickstart"
description: "Clone the repo, create the MySQL database with the required user, build the WAR with Maven, and deploy to GlassFish 7+ to get the system running locally."
---

Esta guía te lleva desde cero hasta tener el sistema del Taller de Inglés ejecutándose en tu máquina local. Clonarás el repositorio, crearás la base de datos MySQL con el usuario correcto, compilarás el archivo WAR con Maven y lo desplegarás en GlassFish. El proceso completo toma menos de diez minutos en un entorno con las herramientas ya instaladas (JDK 11+, Maven, MySQL 8 y GlassFish 7+).

<Steps>
  <Step title="Clonar el repositorio">
    Clona el proyecto desde GitHub y entra al directorio generado:

    ```bash
    git clone https://github.com/LuisAMoralesA/tallerIngles-UAEMEcatepec.git && cd tallerIngles-UAEMEcatepec
    ```
  </Step>

  <Step title="Configurar MySQL">
    Crea la base de datos y el usuario de aplicación. Conéctate a MySQL como root y ejecuta:

    ```sql
    CREATE DATABASE tallerdeingles CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;
    CREATE USER 'adminTallerIngles'@'localhost' IDENTIFIED BY 'UAEMEX_2026';
    GRANT ALL PRIVILEGES ON tallerdeingles.* TO 'adminTallerIngles'@'localhost';
    FLUSH PRIVILEGES;
    ```

    <Warning>
      Las credenciales anteriores (`adminTallerIngles` / `UAEMEX_2026`) son las predeterminadas de desarrollo y están almacenadas directamente en `BaseDatos.configuracionBD`. **No las uses en producción.** Para cambiarlas, edita las constantes `NOMBRE_USUARIO` y `PASSWORD_USUARIO` dentro de la clase `controller/BaseDatos.java` antes de compilar.
    </Warning>
  </Step>

  <Step title="Compilar con Maven">
    Desde la raíz del proyecto, ejecuta el ciclo de construcción estándar de Maven:

    ```bash
    mvn clean package
    ```

    Maven compilará las fuentes Java (requiere **Java 11+**), procesará los recursos y generará el artefacto desplegable en:

    ```
    target/tallerDeInglesUAEM.war
    ```
  </Step>

  <Step title="Desplegar en GlassFish">
    Copia el WAR al directorio `autodeploy` de tu instalación de GlassFish para que el servidor lo detecte y despliegue automáticamente:

    ```bash
    cp target/tallerDeInglesUAEM.war $GLASSFISH_HOME/glassfish/domains/domain1/autodeploy/
    ```

    Una vez desplegado, la aplicación estará disponible en:

    ```
    http://localhost:8080/tallerDeInglesUAEM/
    ```

    Cada rol de usuario tiene su propia página de inicio de sesión:

    | Rol | URL de acceso |
    |---|---|
    | Administradores | `http://localhost:8080/tallerDeInglesUAEM/view/login/loginAdministrador.jsp` |
    | Profesores | `http://localhost:8080/tallerDeInglesUAEM/view/login/loginProfesor.jsp` |
    | Alumnos | `http://localhost:8080/tallerDeInglesUAEM/view/login/loginAlumno.jsp` |
  </Step>
</Steps>
