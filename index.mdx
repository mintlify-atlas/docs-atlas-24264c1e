El **Taller de Inglés para Niños y Adolescentes (TEI)** es una dependencia académica del Centro Universitario UAEM Ecatepec que ofrece enseñanza del idioma inglés a estudiantes de 8 a 15 años. Este sistema web centraliza la gestión de alumnos, profesores, calificaciones, pagos y reportes, reemplazando el manejo manual de información académica.

## Inicio Rápido

<Steps>
  <Step title="Clonar el repositorio">
    ```bash
    git clone https://github.com/LuisAMoralesA/tallerIngles-UAEMEcatepec.git
    cd tallerIngles-UAEMEcatepec
    ```
  </Step>
  <Step title="Configurar la base de datos MySQL">
    Crea la base de datos `tallerdeingles` y el usuario `adminTallerIngles`. Consulta la [guía de base de datos](/installation/database-setup) para el esquema completo.
  </Step>
  <Step title="Compilar y empaquetar">
    ```bash
    mvn clean package
    ```
    Esto genera `target/tallerDeInglesUAEM.war`.
  </Step>
  <Step title="Desplegar en GlassFish">
    Copia el WAR al directorio `autodeploy` de GlassFish o usa la consola de administración. El sistema estará disponible en `http://localhost:8080/tallerDeInglesUAEM/`.
  </Step>
</Steps>

<Note>
  El sistema requiere Java 11+, GlassFish 7 (Jakarta EE 10) y MySQL 8. Consulta los [requisitos completos](/installation/requirements) antes de comenzar.
</Note>
